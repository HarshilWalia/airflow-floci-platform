# Airflow Floci Platform

A hands-on infrastructure engineering project to provision and operate
Apache Airflow on a local Kubernetes environment using Floci.

## Objectives

- Emulate AWS services locally using Floci.
- Understand Kubernetes and EKS architecture.
- Deploy Apache Airflow using Helm.
- Integrate PostgreSQL as the Airflow metadata database.
- Provision infrastructure using Terraform.
- Implement CI/CD using GitHub Actions.
- Explore monitoring, scaling, caching and reliability.
- Practice infrastructure portability across macOS and Windows.

## Technology Stack

- Git and GitHub
- Docker
- Floci
- Kubernetes
- Terraform
- Helm
- Apache Airflow
- PostgreSQL
- AWS CLI
- GitHub Actions
